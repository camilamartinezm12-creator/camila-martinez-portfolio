# Camila Martínez — Portfolio

Two complementary portfolio experiences:

- **Conventional portfolio** at `index.html` — the primary recruiter-facing experience.
- **Interactive journey** at `interactive/index.html` — an evolving joystick-controlled experience featuring an original Mexican calavera mascot.

Both experiences are responsive and bilingual, with English as the default language.
